# =============================================================
# requirements.txt  —  Colab / Kaggle GPU environment
# Install: pip install -r requirements.txt
#
# pip picks one of two sets automatically, by Python version:
#
#  * Python <= 3.12 (Colab, local): exact pins, the tested stack.
#  * Python >= 3.13 (Kaggle): several pins have no 3.13 builds
#    (e.g. Pillow 10.3, pydantic-core 2.18) and Gradio 4 cannot run
#    on 3.13, so a single pinned set would make the WHOLE install
#    fail. There, the platform's preinstalled packages are kept and
#    only missing ones are added (lower bounds). The app supports
#    both Gradio 4.31 and Gradio 5/6.
#
# PyTorch is not listed: Colab and Kaggle preinstall a CUDA build.
# =============================================================
